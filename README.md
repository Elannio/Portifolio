# 🌐 Portfólio Pessoal

Este é o meu **portfólio** desenvolvido com **HTML, CSS e JavaScript**.  
O objetivo é apresentar meus projetos, minhas habilidades e uma forma de contato simples e direta.

## 🚀 Seções do Portfólio
- **Home** → Introdução e links rápidos
- **About** → Um pouco sobre mim
- **Projects** → Lista de projetos desenvolvidos com links para GitHub e Live Demo
- **Contact** → Formas de entrar em contato comigo (LinkedIn, Email)

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
- [Boxicons](https://boxicons.com/) para ícones
